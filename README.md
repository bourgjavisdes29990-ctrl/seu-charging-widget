# 东南大学校内电动车充电桩小组件 (Android Widget + PWA)

> **集成 [Golevka2001/Where-Are-Available-Chargers](https://github.com/Golevka2001/Where-Are-Available-Chargers) 与 [chargers.dpdns.org](https://chargers.dpdns.org/status) 真实数据**
> 专为东南大学**九龙湖校区、丁家桥校区、无锡校区**量身打造的轻量原生手机桌面卡片（4×2）与免安装 PWA 网页全景看板。

---

## 📱 一、产品形态与核心特性

### 1. 轻量原生 Android 桌面卡片 (AppWidget 4×2)
- **多校区智能切换与被动感知**：
  - 自动识别用户身处**九龙湖、丁家桥还是无锡校区**，并自动吸附距离最近的车棚；
  - 45 分钟防跳变保护期：手动点击 `🔄 换车棚` 后维持 45 分钟锁定，避免在校区边界移动时小组件频繁刷新跳变。
- **现代磨砂黑设计 (#0f172a)**：
  - 采用 Deep Slate 磨砂质感卡片，大圆角配微光边框，完美贴合现代 Android 风格；
  - 阶梯分层布局（校区模式 -> 车棚与三色徽章 -> 32sp 粗体空闲大字 -> 快慢充配比与预测 -> 操作栏），彻底杜绝桌面拉伸或多语言字号导致的文字截断。
- **全生态闭环**：
  - 右上角直达按钮：`全校看板 🌐`，一键打开 [Where Are Available Chargers?! (chargers.dpdns.org)](https://chargers.dpdns.org/status)；
  - 底部操作栏：`🔄 换车棚`（当前校区轮换）、`📍 离我最近`（智能感知定位）、`⚡ 刷新`。
- **零后台常驻、零跑电**：
  - `updatePeriodMillis="0"`，无后台持续常驻 Service、无定期唤醒闹钟；
  - 仅在**手机亮屏解锁（`ACTION_USER_PRESENT`）**或**用户主动点击按钮**时毫秒级被动计算更新。

### 2. 免安装 PWA 网页看板 (GitHub Pages)
- **全屏独立运行模式（Standalone）**：支持添加到 iOS / Android 手机桌面，全屏运行无地址栏。
- **严格 Network-First（网络优先）缓存策略**：
  - 优先发起网络请求拉取最新数据，成功后静默更新本地 Cache；
  - 仅在离线时回退到缓存，**彻底规避传统 PWA 手机端被旧缓存卡死的致命痛点**。
- **三校区全覆盖**：支持在九龙湖、丁家桥、无锡校区之间一键筛选，或按“宿舍区”、“教学区”、“余位充裕”、“离我最近”智能排序。

### 3. GitHub Actions 云端全自动打包与部署
- 用户本地**无需安装 Android Studio，无需在电脑上配置 JDK 或 Android SDK**；
- 只要通过 Git 将代码 push 到 GitHub，云端 Ubuntu 容器会自动编译出名为 `seu-charging-widget-v1.0.apk` 的安装包，供手机直接下载安装。

## ⚡ 三、与 Golevka2001/Where-Are-Available-Chargers 数据对接

本工程深度结合了原项目提供的服务与数据通道：
1. **云端拉取**：`ChargingDataManager.java` 异步请求 `https://zwc-backend.chargers.dpdns.org/getProductByDndx.action` 与 `chargers.dpdns.org` 状态通道；
2. **平滑降级与高拟真推算**：在断网、离线、弱网或服务器临时维护时，自动平滑启用针对东南大学作息规律（上下课潮、夜间回寝高峰）的离线仿真模型，**小组件永远不空白、不崩溃**；
3. **网页直达**：小组件一键直达 `https://chargers.dpdns.org/status` 原项目看板。

## 🚀 四、快速部署与使用指南

### 1. 推送到自己的 GitHub 仓库
```bash
git branch -M main
git remote add origin https://github.com/<你的用户名>/seu-charging-widget.git
git push -u origin main
```

### 2. 下载 Android 安装包 (APK)
1. 推送代码后，打开你的 GitHub 仓库，点击顶部 **Actions** 标签；
2. 点击最新的 **Build SEU Charging Widget APK** 流水线运行记录；
3. 在页面底部的 **Artifacts** 区域，点击下载 `seu-charging-widget-v1.0`；
4. 解压后将 `seu-charging-widget-v1.0.apk` 发送到 Android 手机上安装。

### 3. 添加到手机桌面 (Widget 4×2)
1. 手机打开一次「东大电桩」App，授权定位权限（用于智能匹配校区与最近车棚）；
2. 返回手机主屏幕，长按空白处，选择**微件 / 小部件**；
3. 找到「东大电桩」，选择 **4×2** 尺寸卡片拖至桌面即可！

### 4. 开启 GitHub Pages 网页版 (PWA)
1. 在 GitHub 仓库设置中打开 **Settings** -> **Pages**；
2. Source 选择 **Deploy from a branch**，指定 `main` 分支的 `/docs` 目录并保存；
3. 部署完成后用手机浏览器访问，点击「**添加到主屏幕**」即可享受全屏独立 App 体验。
